# Протокол

Локальная запись и обработка совещаний на русском языке. Сотрудник открывает сайт сервера в браузере, разрешает микрофон и при необходимости передачу звука вкладки или экрана. На сервер отправляется аудио; изображение экрана не сохраняется. Установка Windows-клиента для этого режима не нужна. Старый клиент в outputs/protocol-recorder оставлен для истории.

## Запись

На компьютере сотрудника нужен доверенный HTTPS-адрес сервера (localhost допускается без HTTPS). Для звонка используйте Chrome или Edge на Windows: доступность системного аудио зависит от браузера, ОС и выбранного источника демонстрации. Перед встречей проверьте оба индикатора сигнала. Захват системного звука на произвольном мобильном устройстве не гарантируется.

После завершения дождитесь подтверждения приёма сервером. Сохранение в браузере и очередь отправки не означают успешную доставку. Не закрывайте страницу до подтверждения. Состояние обработки и результаты доступны на сайте. Голос сотрудника регистрируется отдельно во вкладке голосов; в образце должен говорить один человек.

## Обработка и модели

Конфигурация: outputs/local-meeting-ai/config.json.

- Текст: faster-whisper, локальный Whisper turbo, русский язык.
- Границы говорящих: pyannote segmentation через sherpa-onnx.
- Голосовые признаки: TitaNet large ONNX, автоматическое число кластеров (num_clusters=-1, порог 1.1). Порог совпадения имени 0.65, минимальный отрыв от второго кандидата 0.10. Это настройки пилота, а не универсальная гарантия точности.
- Сводка и подробный конспект: локальный Qwen3.5-27B-Q4_K_M через llama.cpp, последовательная обработка частей длинной встречи с промежуточными результатами.

Каждая дорожка комнаты или звонка может содержать несколько людей. Источник аудио сам по себе не определяет имя. Неуверенные совпадения остаются неопределёнными. Короткие неуверенные начала фраз группируются с продолжением только для чтения; исходная атрибуция сохраняется и помечается для проверки.

Веса не включены в Git. TitaNet: [sherpa-onnx release](https://github.com/k2-fsa/sherpa-onnx/releases/tag/speaker-recongition-models), файл nemo_en_titanet_large.onnx. Проверенная SHA256: d51abcf31717ef28162f26acb9d44dd4127c3d44c9b8624f699f3425daca8e77. Разместите по пути work/models/speakers/nemo_en_titanet_large.onnx. Модель сегментации model.onnx берётся из sherpa-onnx-pyannote-segmentation-3-0.tar.bz2 в [релизе сегментации](https://github.com/k2-fsa/sherpa-onnx/releases/tag/speaker-segmentation-models). Соблюдайте лицензии распространяемых моделей.

При смене модели признаков профили нужно построить заново из исходных голосовых образцов. Старые векторы WeSpeaker с TitaNet несовместимы; программа теперь отклоняет такое сочетание. Реестр хранит имя модели, а новые образцы — локальные пути исходников для последующего переноса. Не редактируйте только имя модели в реестре: это не преобразует векторы.

## Сервер и данные

Серверный код находится в outputs/local-meeting-ai. Для чистой машины нужны Python, зависимости из requirements.lock.txt, локальные модели и llama.cpp по путям из конфигурации. Скрипты запуска рассчитаны на подготовленное окружение: work/runtime/packages и установленный Python; проверьте пути в launch.ps1 перед переносом на другой сервер.

Ручной запуск: «Открыть Протокол.cmd». Установка запуска до входа пользователя Windows: «Запуск при загрузке Windows.cmd» от администратора. HTTPS подготавливается через prepare_https.py; сертификат должен быть доверенным на клиентских устройствах. Настройки доступа, сертификаты и закрытые ключи создаются локально и не входят в репозиторий.

Под папкой сервера находятся state (очередь и настройки), incoming (приём файлов), recordings (записи), voices (голосовые профили и образцы), results (расшифровки и конспекты), backups (резервные копии). Эти данные исключены из Git. Коммит исходников не заменяет резервное копирование встреч.

## Проверка изменений

python outputs/local-meeting-ai/test_speakers.py проверяет несовместимые профили, отказ от неоднозначного имени, перекрытие голосов и начало реплики с тишиной. Для запуска нужны серверные Python-зависимости в PYTHONPATH.

На локальной тестовой встрече проверены шесть размеченных пользователем точек и повторная регистрация обоих голосов. Число участников не задавалось вручную. Остались короткие неопределённые фрагменты. Это проверка одного материала, не измерение точности на всех микрофонах и участниках. Исходная запись и персональные профили не публикуются.
